# Prerender SvelteKit for Hostinger

The Catwalk 21 website will be rebuilt as a marketing site in SvelteKit, prerendered to static files for Hostinger's `public_html`. This keeps the existing hosting model and avoids a production Node server while allowing component-based UI development. Hostinger Single Web Hosting uses the classic Git connector, which copies repository files into `public_html` without running a build. Hostinger currently deploys `master`. Keep `master` as the generated-site branch, put SvelteKit source on `main`, and trigger CI builds only from `main` using `@sveltejs/adapter-static`. After checks and preview, CI publishes only the generated site's files to the root of `master`, where Hostinger can continue pulling them without a connector change. Do not publish SvelteKit source, credentials, or build tooling to `master`. Preview before cutover and keep the previous release for rollback. Confirm whether Hostinger removes files deleted from the artifact branch, so old PHP/template files are not left public. The existing logo artwork stays unchanged. This decision does not include online booking, a CMS, or the legacy PHP contact endpoint.
